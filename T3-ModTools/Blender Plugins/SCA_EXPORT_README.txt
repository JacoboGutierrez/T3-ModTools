T3 SCA BLENDER EXPORTER
=======================

FILE
----
T3_Blender_SCA_Exporter.py

PURPOSE
-------
This experimental Blender add-on exports selected static or rigged mesh objects to the
text-based T3 .sca model format. It is intended for replacement-model mod projects.

INSTALLATION
------------
1. Open Blender.
2. Select Edit > Preferences > Add-ons.
3. Click Install from Disk.
4. Select T3_Blender_SCA_Exporter.py.
5. Enable T3 SCA Model Exporter.

EXPORT
------
1. Select the mesh objects to export. A compatible armature may also be selected or linked
   through an Armature modifier.
2. Apply object transforms and triangulate or validate the model before export.
3. Use File > Export > T3 Model (.sca).
4. Set the internal Texture library path used by the target game asset.
5. Keep "Undo T3-ModTools X mirror" enabled when exporting a model that originated from
   a mirrored glTF generated by T3-ModTools and whose transforms were applied in Blender.

The exporter writes geometry, normals, UV0, base-material texture names, vertex weights,
bone hierarchy, bind matrices, instances, and a bounding box.

LIMITATIONS
-----------
- Experimental: test the result as a replacement of a backed-up asset before wider use.
- It does not currently export LOD files, map scene.sca binary trees, scene.det, scene.dyn,
  collision targets, advanced shader parameters, lightmaps, or game-specific entity logic.
- It does not create a new playable character, weapon, or vehicle registration by itself.
  The required game configuration files must also be included in the mod.
- Blender modifiers are not applied automatically. Apply required modifiers before export.
- Keep bone names compatible with the target rig and animation files.
