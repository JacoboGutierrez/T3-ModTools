T3-MODTOOLS 0.6.5 TEST REPORT
================================

LOADER HOTFIX EVIDENCE
----------------------

- The user-reported crash occurred at EIP 0x0044D8C1 during a menu lookup.
- A live empty-string sentinel at VA 0x00688040 instead contained DER_V2, bytes from the
  enlarged loader path/marker in the initial 0.6.5 executable. This corrupted the lookup
  and caused the observed null-pointer failure.
- The correction allocates loader code and path data in an appended .t3ldr RX section.
  Original sections are preserved except for the six-byte loader hook and mod patches;
  the PE headers are updated to describe the added section.
- Recognized legacy loaders are verified against their bytes and manifest fingerprints,
  their original storage is restored, and the new section is installed while preserving
  existing mod patches. Launch requires this corrected loader.
- The game has not been launched as part of this hotfix verification.

LIMITATIONS
-----------

- Launching the Windows game executable is outside the automated test suite.
- The version 1 executable patch format supports aob_replace and aob_write for T3.exe and Ai.Dll.
- Mod packs freeze generated executable patches; future source changes require a new pack.
- Generate mod pack preserves asset text and existing patch descriptions; it does not translate
  third-party documentation or bundle development scripts outside files/.
- Console localization does not rewrite third-party prose, file paths, IDs, hashes, or
  technical exception data; raw details remain available in diagnostic files.
- Runtime patch generators execute local Python code and must only be used from trusted mods.
